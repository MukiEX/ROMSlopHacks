Puchi Carat Translation Kit

puchicar · Ver 2.02O

Translate the full story dialogue, page by page

Open the World ROM set, puchicar.zip (Ver 2.02O). It holds the full Japanese script too: the World release only hides the dialogue, it never removed it. Every one of the 991 dialogue pages appears here drawn with the game's own font, so you can flip through, screenshot, copy the Japanese, and type English underneath. The ROM never leaves your browser.

  1. English is drawn two letters per tile with a new half-width font in Taito's outline-and-shadow style, so a 10-tile story box holds 20 letters per line.
  2. Hearts, sweat drops, notes and other custom glyphs stay available from a picker, along with the six text colours.
  3. Build patched ROM writes the script into the empty upper 1 MB of the program ROM, repoints all 429 text pointers and draws the letter pairs into unused kanji tiles. It outputs a World set: the World release's English intro, title, menus, name plates and attract tutorial, with the story dialogue, ending wishes and character profiles the World release cut switched back on. You get a zip plus a MiSTer MRA.
